# I. Idea and Its Validation

## 1.1 The Idea

ElectroMart is a marketplace e-commerce application, branded "All Kind of Electronics," built in Python using the Flet framework so that a single codebase can be deployed across Web, Desktop (Windows, Linux, macOS) and Mobile (Android, iOS). The platform allows buyers and sellers to interact on one system: sellers list electronic products or services, buyers search and compare them, and both parties are supported through secure authentication, a shopping cart, checkout, and order management.

## 1.2 Validation of the Idea

**Market validation:** Established players such as Konga, Jumia, AliExpress, Slot and Jiji show strong existing demand for online electronics retail in the target market, confirming that buyers already trust and use this channel. ElectroMart validates a niche within that demand by focusing exclusively on electronics and by surfacing a built-in price comparison against these competitor platforms, giving buyers a concrete reason to check ElectroMart before purchasing elsewhere.

**User validation:** The two core user groups — buyers seeking electronics and sellers wanting a channel to list them — mirror the roles already served (and generally well received) on the reference platforms, indicating the two-sided marketplace model is viable rather than speculative.

**Technical validation:** Python with Flet (and Flutter-based cross-platform support) is a proven approach for shipping one codebase to Web, Desktop and Mobile, which validates that the cross-platform target set out in the assignment is achievable without maintaining separate codebases per platform.

**Regulatory/trust validation:** Building in NDPA 2023/GDPR-aligned data handling and ISO/SON-oriented product-quality and accessibility considerations from the outset validates that the idea can operate within the same compliance environment that incumbent marketplaces already work under.

**Conclusion:** The idea is validated as a realistic, demand-backed, technically achievable coursework project with a credible path from MVP to a genuine niche marketplace.
