# ElectroMart — SDLC Documentation Set

This folder holds the supporting documentation for **ElectroMart**, produced
against the course's AI-Native Software Development framework
(Theories → Principles → Standards, applied through the SDLC).

The app itself (`ElectroMart.html`) is the working Proof of Concept / MVP.
These files are the artifacts the framework expects around it, one per
phase, numbered so they stay in a consistent order:

| # | File | SDLC Phase |
|---|---|---|
| 01 | `01-problem-statement.md` | Analysis — Statement of the Problem |
| 02 | `02-feasibility-study.md` | Analysis — Feasibility Study (SMART) |
| 03 | `03-system-requirements.md` | Analysis — Requirements Elicitation (system requirements) |
| 04 | `04-wireframes.md` | Analysis — Proof of Concept / UI Wireframes |
| 05 | `05-design-frontend.md` | Design — Frontend concern |
| 06 | `06-design-logic.md` | Design — Logic concern |
| 07 | `07-design-backend.md` | Design — Backend concern |
| 08 | `08-development-decisions.md` | Development — tooling & environment choices |
| 09 | `09-testing-plan.md` | Testing — Alpha / Beta / UAT |
| 10 | `10-deployment-plan.md` | Deployment — platform, staging, release |

Functional and non-functional requirements, and the ISO/SON/NDPA/GDPR
standards references, are documented in the app itself (footer →
**Requirements** / **Standards & Certification**) rather than duplicated
here — 03–10 above cross-reference that content instead of repeating it.

The app has also grown a matching **Project Docs** section in its footer
(alongside the existing Terms/Privacy/Returns/Requirements/Standards
links) so a reviewer can read condensed versions of 01, 04, and 09–10
without leaving the running app.
